# Owl Backend Foundation (Build Steps 3–4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the Python backend for Owl: a FastAPI app connected to Supabase Postgres, with all seven database tables created through Alembic migrations, startup safety checks, and a test setup that can never touch the real database.

**Architecture:** A `backend/` folder managed by `uv`. `app/config.py` reads settings from `.env`; `app/database.py` owns the database connection; `app/models.py` describes every table as a Python class; Alembic turns those classes into real tables, one numbered migration at a time. `app/main.py` creates the FastAPI app, runs startup checks, and serves `GET /api/health`. Tests run against a **separate** Supabase project configured in `.env.test`.

**Tech Stack:** Python 3.14, uv, FastAPI, SQLAlchemy 2.0 (sync style), psycopg 3, Alembic, pgvector, pydantic-settings, pytest.

**Spec:** `docs/superpowers/specs/2026-11-19-owl-rag-mvp-design.md` (sections 2, 3, 4, 10, 11, 12).

**Learner mode (owner's standing request):** The owner has no Python background. Before writing or changing any file, the implementer:
1. shows the **file map** for the task (each file and its one-line purpose),
2. explains the code in plain language **before** writing it, including the Python ideas listed under "Python ideas" in the task,
3. writes the code,
4. has the owner run the commands and check the result.

## Global Constraints

- All backend code lives in `backend/`. Run every `uv` command from inside `backend/`. Shell commands are written for **Git Bash**.
- Python **3.14**, managed by **uv** (`uv run ...` always uses the project's own environment).
- Supabase is used as **plain Postgres only** (spec section 2). No Supabase Auth, Storage or client libraries. Only standard SQL plus the `vector` extension.
- `DATABASE_URL` uses the Supabase **Session pooler** connection string. The app converts `postgresql://` to `postgresql+psycopg://` automatically.
- **Sync style** SQLAlchemy and FastAPI (`def`, not `async def`) everywhere except FastAPI's startup `lifespan` hook, which FastAPI requires to be async.
- `.env` and `.env.test` are never committed (already covered by the root `.gitignore`); `.env.example` is committed.
- Tests **must never** use the real database: `tests/conftest.py` refuses to run unless `.env.test` exists and its `DATABASE_URL` differs from `.env`.
- Embeddings are `vector(1024)` (spec section 2).
- Status values: documents `processing` / `ready` / `failed`; messages `user` / `assistant` (spec section 4).
- `/api/health` is public and returns only `{"status": "ok"}` (HTTP 200) or `{"status": "not ok"}` (HTTP 503) (spec section 8).
- Startup: refuse to start if the database is unreachable or the `vector` extension is missing; mark **every** `processing` document as `failed` with reason "Processing was interrupted, please upload again." (spec section 3).
- Database rules (spec section 4): unique (`user_id`, `content_hash`) on documents; deleting a document deletes its chunks; deleting a conversation deletes its messages; deleting a user deletes everything of theirs; indexes on `chunks.user_id`, `documents.user_id`, `conversations.user_id`, `messages.conversation_id`; `usage` primary key (`user_id`, `day`).
- **Row Level Security (RLS) is enabled on every table in the `public` schema**, including `alembic_version`, with no policies. This blocks Supabase's automatic Data API (which uses a public key) from reading or writing any table. The backend connects as the tables' owner, which RLS does not restrict, so Owl keeps working. RLS is standard Postgres, so this stays portable. The backend refuses to start if any `public` table has RLS turned off.

```python
from functools import lru_cache

from pydantic import field_validator
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    """Every setting Owl needs, read from environment variables or the .env file."""

    model_config = SettingsConfigDict(env_file=".env", extra="ignore")

    database_url: str

    @field_validator("database_url")
    @classmethod
    def use_psycopg_driver(cls, value: str) -> str:
        # Supabase gives "postgresql://..."; SQLAlchemy needs to know which driver to use.
        for prefix in ("postgresql://", "postgres://"):
            if value.startswith(prefix):
                return "postgresql+psycopg://" + value.removeprefix(prefix)
        return value


@lru_cache
def get_settings() -> Settings:
    return Settings()
```

```python
from collections.abc import Iterator

from sqlalchemy import create_engine, text
from sqlalchemy.orm import Session, sessionmaker

from app.config import get_settings

# The engine keeps a small pool of open connections to Postgres and reuses them.
engine = create_engine(get_settings().database_url, pool_pre_ping=True, pool_size=5, max_overflow=5)

# A session is one "conversation" with the database: reads, changes, then commit.
SessionLocal = sessionmaker(bind=engine, autoflush=False, expire_on_commit=False)


def get_db() -> Iterator[Session]:
    """Give a route its own session and always close it afterwards."""
    with SessionLocal() as session:
        yield session


def database_is_reachable() -> bool:
    try:
        with engine.connect() as connection:
            connection.execute(text("SELECT 1"))
        return True
    except Exception:
        return False
```

Replace `backend/alembic/env.py`:

```python
from logging.config import fileConfig

from alembic import context
from sqlalchemy import engine_from_config, pool

from app.config import get_settings
from app.models import Base

config = context.config

if config.config_file_name is not None:
    fileConfig(config.config_file_name)

# Use the same database as the app (from .env or the test environment), never a URL typed into alembic.ini.
# "%" is doubled because alembic.ini treats a single "%" as special.
config.set_main_option("sqlalchemy.url", get_settings().database_url.replace("%", "%%"))

target_metadata = Base.metadata


def run_migrations_offline() -> None:
    context.configure(
        url=config.get_main_option("sqlalchemy.url"),
        target_metadata=target_metadata,
        literal_binds=True,
        dialect_opts={"paramstyle": "named"},
    )
    with context.begin_transaction():
        context.run_migrations()


def run_migrations_online() -> None:
    connectable = engine_from_config(
        config.get_section(config.config_ini_section, {}),
        prefix="sqlalchemy.",
        poolclass=pool.NullPool,
    )
    with connectable.connect() as connection:
        context.configure(connection=connection, target_metadata=target_metadata)
        with context.begin_transaction():
            context.run_migrations()


if context.is_offline_mode():
    run_migrations_offline()
else:
    run_migrations_online()
```

```python
def upgrade() -> None:
    op.execute("CREATE EXTENSION IF NOT EXISTS vector")
    # Alembic creates this table before the first migration runs; lock it from Supabase's public Data API right away.

    op.execute('ALTER TABLE "alembic_version" DISABLE ROW LEVEL SECURITY')
    op.execute("DROP EXTENSION IF EXISTS vector")
```

```python
import pytest
from sqlalchemy import func, select
from sqlalchemy.exc import IntegrityError

from app.database import tables_without_row_level_security
from app.models import EMBEDDING_DIMENSIONS, Chunk, Conversation, Document, Message, User


def make_user(db, email="reader@example.com"):
    user = User(email=email, password_hash="not-a-real-hash")
    db.add(user)
    db.commit()
    return user


def make_document(db, user, content_hash="a" * 64, status="ready"):
    document = Document(
        user_id=user.id,
        filename="notes.md",
        file_type="md",
        content_hash=content_hash,
        status=status,
    )
    db.add(document)
    db.commit()
    return document


def count(db, model):
    return db.scalar(select(func.count()).select_from(model))


def test_same_user_cannot_upload_the_same_file_twice(db):
    user = make_user(db)
    make_document(db, user)

    with pytest.raises(IntegrityError):
        make_document(db, user)


def test_different_users_can_upload_the_same_file(db):
    make_document(db, make_user(db, "one@example.com"))
    make_document(db, make_user(db, "two@example.com"))

    assert count(db, Document) == 2


def test_document_status_must_be_a_known_value(db):
    with pytest.raises(IntegrityError):
        make_document(db, make_user(db), status="almost-done")


def test_deleting_a_document_deletes_its_chunks(db):
    user = make_user(db)
    document = make_document(db, user)
    db.add(
        Chunk(
            user_id=user.id,
            document_id=document.id,
            text="Owls can rotate their heads 270 degrees.",
            position=0,
            embedding=[0.1] * EMBEDDING_DIMENSIONS,
            embedding_model="test-model",
        )
    )
    db.commit()

    db.delete(document)
```

```python
def tables_without_row_level_security(session: Session) -> list[str]:
    """Names of tables in the public schema that have Row Level Security turned off."""
    rows = session.scalars(
        text(
            "SELECT c.relname FROM pg_class c "
            "JOIN pg_namespace n ON n.oid = c.relnamespace "
            "WHERE n.nspname = 'public' AND c.relkind = 'r' AND NOT c.relrowsecurity "
            "ORDER BY c.relname"
        )
    )
    return list(rows)
```

```python
TABLES = [

    "conversations",

    "usage",

def upgrade() -> None:

    # The backend owns the tables, so RLS does not restrict it.
    for table in TABLES:
        op.execute(f'ALTER TABLE "{table}" ENABLE ROW LEVEL SECURITY')


def downgrade() -> None:
    for table in TABLES:
        op.execute(f'ALTER TABLE "{table}" DISABLE ROW LEVEL SECURITY')
```

Create `backend/app/startup.py`:

```python
from sqlalchemy import text, update
from sqlalchemy.orm import Session

from app.database import tables_without_row_level_security
from app.models import Document

INTERRUPTED_REASON = "Processing was interrupted, please upload again."


class StartupCheckError(RuntimeError):
    """Something is wrong enough that Owl must not start."""


def check_database(session: Session) -> None:
    try:
        session.execute(text("SELECT 1"))
    except Exception as error:
        raise StartupCheckError("Can't reach the database. Check DATABASE_URL in backend/.env.") from error

    vector_installed = session.execute(text("SELECT 1 FROM pg_extension WHERE extname = 'vector'")).first()
    if vector_installed is None:
        raise StartupCheckError("The pgvector extension is missing. Run: uv run alembic upgrade head")

    unprotected = tables_without_row_level_security(session)
    if unprotected:
        raise StartupCheckError(
            "Row Level Security is off for: " + ", ".join(unprotected) + ". Add a migration that enables it."
        )


def mark_interrupted_documents(session: Session) -> int:
    """Only one backend runs, so after a restart nothing can still be processing these."""
    result = session.execute(
        update(Document)
        .where(Document.status == "processing")
        .values(status="failed", failure_reason=INTERRUPTED_REASON)
    )
    session.commit()
    return result.rowcount
```

```python
import logging
from contextlib import asynccontextmanager

from fastapi import FastAPI, Response, status

from app.database import SessionLocal, database_is_reachable
from app.startup import check_database, mark_interrupted_documents

logger = logging.getLogger("owl")


@asynccontextmanager
async def lifespan(app: FastAPI):
    # Runs once when the server starts. An error here stops the server with a clear message.
    with SessionLocal() as session:
        check_database(session)
        interrupted = mark_interrupted_documents(session)
    if interrupted:
        logger.warning("Marked %d interrupted document(s) as failed.", interrupted)
    yield


app = FastAPI(title="Owl API", lifespan=lifespan)


@app.get("/api/health")
def health(response: Response) -> dict[str, str]:
    if database_is_reachable():
        return {"status": "ok"}
    response.status_code = status.HTTP_503_SERVICE_UNAVAILABLE
    return {"status": "not ok"}
```
