# Owl Frontend UI (Build Steps 1–2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Owl frontend (React app) with every page laid out and styled, showing static sample content, so the whole app can be clicked through before any backend exists.

**Architecture:** A Vite + React + TypeScript single-page app in `frontend/`. React Router maps URLs to pages, which sit inside two layouts: a centered card layout for auth pages and a sidebar layout for the app. All sample content lives in one file (`src/data/sampleData.ts`); forms validate input for real, but every action that would need the backend shows a "not connected yet" toast instead.

**Tech Stack:** Vite, React 19, TypeScript, Tailwind CSS v4, shadcn/ui (Radix), React Router v7, Zustand, React Hook Form + Zod, Sonner (toasts), lucide-react (icons).

**Spec:** `docs/superpowers/specs/2026-11-19-owl-rag-mvp-design.md` (sections 9 and 12).

**Learner mode:** The project owner is learning. Each task starts with a short "What you'll learn" note. After each task the owner runs the app and checks the result in the browser before moving on.

## Global Constraints

- All frontend code lives in `frontend/`. Run every `npm` / `npx` command from inside `frontend/`.
- Shell commands are written for **Git Bash** (`rm`, `cp`, `grep`). On Windows, run them in Git Bash, not PowerShell.
- shadcn/ui must use the **Radix UI** primitives (components use the `asChild` prop). If `shadcn init` asks which component library to use, choose Radix.
- Theme colors (from the Owl logo): deep purple `#5B2A86` (primary), amber `#F2A33A` (highlight), navy `#1F2A44` (text). Light and dark mode.
- Sample content lives **only** in `src/data/sampleData.ts`.
- Nothing simulates backend behavior. Actions that need the backend call `notConnected(...)`, which shows a toast.
- Zustand holds only UI state that several components share (theme, sidebar open). State used by a single component stays in `useState`. The selected conversation comes from the URL (`/chat/:conversationId`), never from Zustand. (The streaming-answer state from spec section 9 is added in build step 7, when streaming exists.)
- TanStack Query is **not** installed in this plan; it arrives in build step 5 with the backend.
- No frontend tests in this plan (spec section 10: Vitest arrives in step 5). Each task is verified with `npm run build` (type check + build), `npm run lint`, and a manual browser check.
- Pages must work at phone width (375 px) and in dark mode.
- Forms: email must be valid; new passwords 10–128 characters (spec section 5).
- Sign-up page shows the privacy note: document text is sent to Voyage AI and Anthropic.
- Download buttons and the "Forgot password?" link appear only when the matching optional feature is on (`sampleConfig.storageEnabled` / `sampleConfig.emailEnabled` for now; `/api/config` later).

- [ ] **Step 3: Create the UI store and theme hook**

Create `frontend/src/stores/uiStore.ts`:

```ts
import { create } from "zustand"
import { persist } from "zustand/middleware"

export type Theme = "light" | "dark"

type UiState = {
  theme: Theme
  sidebarOpen: boolean
  toggleTheme: () => void
  setSidebarOpen: (open: boolean) => void
}

const prefersDark = window.matchMedia("(prefers-color-scheme: dark)").matches

export const useUiStore = create<UiState>()(
  persist(
    (set) => ({
      theme: prefersDark ? "dark" : "light",
      sidebarOpen: true,
      toggleTheme: () => set((state) => ({ theme: state.theme === "dark" ? "light" : "dark" })),
      setSidebarOpen: (open) => set({ sidebarOpen: open }),
    }),
    {
      name: "owl-ui",
      // Only the theme is remembered between visits.
      partialize: (state) => ({ theme: state.theme }),
    },
  ),
)
```

Create `frontend/src/hooks/useApplyTheme.ts`:

```ts
import { useEffect } from "react"
import { useUiStore } from "@/stores/uiStore"

export function useApplyTheme() {
  const theme = useUiStore((state) => state.theme)

  useEffect(() => {
    document.documentElement.classList.toggle("dark", theme === "dark")
  }, [theme])
}
```

import { z } from "zod"

const email = z.email({ error: "Enter a valid email address" })

const newPassword = z
  .string()
  .min(10, { error: "Use at least 10 characters" })
  .max(128, { error: "Use at most 128 characters" })

export const loginSchema = z.object({
  email,
  password: z.string().min(1, { error: "Enter your password" }),
})

export const signupSchema = z
  .object({
    email,
    password: newPassword,
    confirmPassword: z.string(),
  })
  .refine((values) => values.password === values.confirmPassword, {
    error: "Passwords don't match",
    path: ["confirmPassword"],
  })

export const forgotPasswordSchema = z.object({ email })

export const resetPasswordSchema = z
  .object({
    password: newPassword,
    confirmPassword: z.string(),
  })
  .refine((values) => values.password === values.confirmPassword, {
    error: "Passwords don't match",
    path: ["confirmPassword"],
  })

export type LoginValues = z.infer<typeof loginSchema>
export type SignupValues = z.infer<typeof signupSchema>
export type ForgotPasswordValues = z.infer<typeof forgotPasswordSchema>
export type ResetPasswordValues = z.infer<typeof resetPasswordSchema>

type FormFieldProps = ComponentProps<typeof Input> & {
  id: string
  label: string
  error?: string
}

export function FormField({ id, label, error, ...inputProps }: FormFieldProps) {
  const errorId = `${id}-error`

  return (
    <div className="grid gap-2">
      <Label htmlFor={id}>{label}</Label>
      <Input id={id} aria-invalid={error ? true : undefined} aria-describedby={error ? errorId : undefined} {...inputProps} />
      {error && (

          {error}

    </div>

import { useRef, useState, type DragEvent } from "react"
import { Upload } from "lucide-react"
import { Button } from "@/components/ui/button"
import { notConnected } from "@/lib/notConnected"
import { cn } from "@/lib/utils"

export function UploadDropzone() {
  // Only this component needs to know about dragging, so it's local state, not Zustand.
  const [isDragging, setIsDragging] = useState(false)
  const fileInputRef = useRef<HTMLInputElement>(null)

  function handleDrop(event: DragEvent<HTMLDivElement>) {
    event.preventDefault()
    setIsDragging(false)
    notConnected("Uploading")
  }

  return (
    <div
      onDragOver={(event) => {
        event.preventDefault()
        setIsDragging(true)
      }}
      onDragLeave={() => setIsDragging(false)}
      onDrop={handleDrop}
      className={cn(
        "flex flex-col items-center gap-3 rounded-lg border-2 border-dashed p-8 text-center transition-colors",
        isDragging ? "border-primary bg-primary/5" : "border-border",

        Choose files
      </Button>
      <input
        ref={fileInputRef}
        type="file"
        accept=".pdf,.docx,.txt,.md"
        multiple
        className="hidden"

- [ ] **Step 3: Create the chat input**

Create `frontend/src/components/ChatInput.tsx`:

```tsx
import { useState, type FormEvent, type KeyboardEvent } from "react"
import { SendHorizontal } from "lucide-react"
import { Button } from "@/components/ui/button"
import { Textarea } from "@/components/ui/textarea"
import { notConnected } from "@/lib/notConnected"

export function ChatInput() {
  const [question, setQuestion] = useState("")
  const canSend = question.trim().length > 0

  function send(event?: FormEvent) {
    event?.preventDefault()
    if (!canSend) return
    notConnected("Asking questions")
  }

  function handleKeyDown(event: KeyboardEvent<HTMLTextAreaElement>) {
    // Enter sends; Shift+Enter adds a new line.
    if (event.key === "Enter" && !event.shiftKey) {
      event.preventDefault()
      send()
    }
  }

  return (
    <form onSubmit={send} className="flex items-end gap-2">
      <Textarea
        value={question}
        onChange={(event) => setQuestion(event.target.value)}
        onKeyDown={handleKeyDown}
        placeholder="Ask about your documents…"
        aria-label="Your question"
        rows={1}
        className="max-h-40 min-h-10 resize-none"
      />
      <Button type="submit" size="icon" disabled={!canSend} aria-label="Send question">
        <SendHorizontal />
      </Button>
    </form>
  )
}
```
